## 📌 Overview
Digital School is an online schooling system that enables teachers and students to collaborate through classrooms, assignments, and file sharing. It comes with role-based authentication, a drag-and-drop form builder, and modern UI components.

## 🚀 Features

✅ Backend built with Django REST Framework <br/>
✅ Frontend using Next.js + Shadcn UI <br/>
✅ JWT Authentication for secure access <br/>
✅ Role-based Authorization (Admin, Staff, Teacher, Student) <br/>
✅ MySQL as the database <br/>
✅ Redux for global state management <br/>
✅ Form Builder using DnD Kit (drag & drop) <br/>
✅ Create classrooms & classworks <br/>
✅ File upload support for assignments <br/>

## 🛠️ Tech Stack
- Backend: Django REST Framework
- Frontend: Next.js + Shadcn UI
- Database: MySQL
- Authentication: JWT + Role-based
- State Management: Redux
- Data Fetching: React Query
- Form Builder: DnD Kit

## ⚡ Getting Started
1️⃣ Clone the repo
```bash
git clone https://github.com/AlifHossain27/Digital-School.git
cd Digital-School
```

2️⃣ Backend Setup (Django)
```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

3️⃣ Frontend Setup (Next.js)
```bash
cd frontend
npm install
npm run dev
```

4️⃣ Access
- Backend: http://localhost:8000
- Frontend: http://localhost:3000
